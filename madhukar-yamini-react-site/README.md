# Madhukar Reddy & Yamini — Premium Wedding Invitation

A responsive React + Vite wedding invitation with royal maroon-and-gold styling, cinematic couple-photo opening, Telugu/English toggle, countdown, photo gallery, calendar download, and venue directions.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.
4. Build production files with `npm run build`; the deployable site is created in `dist/`.

## Cloudflare Pages Direct Upload
Upload the **contents of `dist/`** (or zip the contents of `dist/`) in Cloudflare Pages > Create application > Pages > Drag and drop your files.
